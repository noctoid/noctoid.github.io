# About Me

Hi — I'm the author of this site. I write about retro computing, software,
and the things I'm building.

This site is a little retro experiment: a Windows 98 desktop rendered in the
browser. Everything you see — the windows, the taskbar, the start menu — is
just HTML, CSS, and Vue.

Thanks for stopping by.
